# 阅读 Web 界面原型 v1

打开 `index.html` 即可体验，无依赖、无需连接 App。示例书籍、封面、正文、书源和连接状态均为演示数据，状态只保存在页面内存中。刷新页面重置。此阶段用于确认信息架构和交互，不替换现有 Vue 页面或 Android 内置资源。

## 现有功能与设计对应

| 现有实现 | 原型中的位置与调整 |
| --- | --- |
| `BookShelf.vue`：书架、最近阅读、书架过滤、在线搜索、连接设置 | 统一左侧导航；书架突出继续阅读；本地过滤与在线搜索明确分开；连接设置独立页面 |
| `BookItems.vue`：封面、作者、章节与更新信息 | 封面网格 / 列表切换；点击打开阅读；强化阅读进度层级，完整章节元信息留待实现阶段补齐 |
| `BookChapter.vue`、`PopCatalog.vue`：阅读、目录、章节切换、进度同步 | 中央阅读区；桌面目录侧栏；窄屏目录展开；专注模式；上下章及方向键切章 |
| `ReadSettings.vue`：主题、字体、字号、间距、宽度、翻页速度、无限加载 | 核心排版选项常驻，其余折叠；字号、行距、字距、段距、宽度、本机字体实时预览；速度与无限加载只记录选择 |
| `SourceEditor.vue`、`SourceTabForm.vue`：书源 / 订阅源规则表单 | 源列表 + 规则工作区；书源按基础 / 搜索 / 发现 / 详情 / 目录 / 正文分区；订阅源按基础 / 列表 / 内容分区 |
| `SourceJson.vue`、`SourceTabTools.vue` | 表单 / JSON 切换；编辑状态；JSON 格式校验与双向同步；规则帮助入口 |
| `ToolBar.vue`：拉取、推送、保存、调试、清空、撤销、快捷键 | 顶部批量操作、底部当前源操作；覆盖与清空确认；可操作演示；Ctrl / Cmd + S 保存 |
| `SourceDebug.vue`：WebSocket 调试 | 在当前编辑区下方展示运行与结果状态，不离开规则上下文 |
| `connectionStore.ts`、`api/axios.ts`：服务地址与连接状态 | 导航底部连接入口；独立连接卡片；原型校验 URL，不验证真实连接 |

## 视觉方案

- 参考根目录 `ui-redesign-preview.html`：主色 `#6C5CE7`、暖灰底色、圆角与深浅主题；Web 布局使用更克制的阴影与更高的信息密度。
- 阅读区用纸张底色与衬线正文；管理区用中性色表单和清晰分隔。书封为 CSS 生成的原创示例，无远程图像依赖。
- 桌面采用固定宽度侧栏与自适应内容区；600px 以下导航改为顶部换行入口；规则列表与编辑区堆叠；书架两列展示。
- 提供键盘焦点、跳过导航、表单标签、弹窗焦点管理、进度语义与状态播报。图标按钮有文字替代说明。

## 可体验路径

1. 书架 → 筛选 / 搜索 / 排序 / 列表 → 继续阅读 → 目录切章 → 调整排版 → 专注阅读。
2. 在线搜索 → 输入“山海”或“星河” → 搜索结果 → 加入并阅读（演示书籍已在书架，模拟入口）。
3. 书源或订阅源 → 选择源 → 编辑规则 → JSON 同步 → 格式错误提示 → 撤销 → 保存 → 演示调试。
4. 批量推送、清空及删除 → 确认弹窗；连接设置 → URL 格式校验 → 演示连接 / 断开。
5. 顶栏主题切换 → 任意页面深浅模式。

## 实现阶段范围

确认此方向后在现有 Vue3 + Element Plus 项目中提取统一 Layout、导航、设计 token、书籍卡片、源编辑工作区。保留现有 HTTP / WebSocket API、Pinia 状态、读取及保存进度语义，不需要新增数据库实体。

原型覆盖主要使用路径，不宣称全功能替代。正式实现必须补齐完整规则配置、章节与更新元信息、源批量选择及列表操作、自定义网络字体、完整快捷键编辑，以及真实加载、空结果、断连、错误重试、推送部分失败和切页未保存提示。书籍删除 API 已存在，但当前书架组件没有删除入口，新增管理入口需单独确认。发现规则只提供编辑，不增加未经现有 Web 支持的在线发现内容页；订阅页仅管理订阅源，不增加 RSS 文章阅读器或 Android AI Agent 入口。

原型未复制到 `app/src/main/assets/web/vue/`，APK 构建与安装不会让此原型出现在 App 的 Web 服务中。
