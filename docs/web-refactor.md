# Web 界面重构

沿用 `docs/web-prototype/` 的暖灰和统一导航，强调色跟随 App 当前主题；实际页面使用 App 的 HTTP / WebSocket 接口，没有嵌入原型演示数据。

- 统一入口：书架、在线搜索、书源、订阅源、连接设置；原有哈希路径保留，旧页面入口使用同一套路由。
- 服务根地址的导航首页采用浏览器起始页布局：应用图标 + Legado、居中书籍搜索条、书架 / 书源 / 传书 / 订阅源四个快捷入口。搜索提交跳转在线搜索并自动开始搜索，支持中文与特殊字符；强调色和深浅主题通过现有配置接口同步，右上角保留连接设置入口，桌面与手机均适配。
- 书架：最近阅读卡片、章节进度估算、筛选、排序、网格 / 列表、真实封面与失败占位。保留最新章节、已读章节及更新时间。
- 阅读：独立阅读布局、持续可见的工具栏、目录 / 排版抽屉、专注模式、章节切换、方向键、正文图片代理、无限加载及进度同步。
- 正文图片统一走 App `/image` 代理，包括普通 HTTP/HTTPS、相对路径和阅读特殊参数图片；独立段落与内嵌图片都不再先尝试浏览器直连。内嵌图片移除 `srcset`，避免绕过代理；沿用 App 的书源请求头、图片缓存和解密逻辑，不再失败后重复代理请求。已使用本地测试服务验证独立、内嵌及相对路径图片均加载成功。
- 书籍封面统一走 App `/cover` 代理，覆盖书架、最近阅读与搜索结果。保留自定义封面优先、懒加载及加载失败占位；不再先直连源站或失败后重复代理。
- 源管理：源列表 + 编辑工作区，保留导入、导出、批量删除 / 推送、完整规则字段及快捷键编辑。基础高级字段折叠；表单 / JSON 双向同步，错误 JSON 阻止保存和调试；离开与切源提示未保存修改。
- 连接：校验服务地址和真实阅读配置，成功后再更新 HTTP / WebSocket 地址及配置。
- 强调色：`getReadConfig` 始终附带 ThemeStore 当前的 `appAccentColor`，未保存过阅读配置时也可获取。Web 初次加载、返回前台、切换连接及可见页面每 15 秒更新强调色；只更新主题颜色，不覆盖正在调整的阅读排版。深浅主题自动生成按钮、导航、目录选中与进度条色阶，亮色按钮使用深色文字；旧版 App 或无效颜色回退到默认主题。强调色不会通过 Web 阅读设置回写 App。
- 修复整合后的接口初始化循环、源类型固定、搜索关键字 JSON 转义，以及编辑器撤销 / 重做行为。

验证使用独立本地测试服务（未向用户 App 写入测试书籍或书源），覆盖书架过滤、正文及切章、源 JSON 校验与同步、撤销 / 重做、保存、两种源的 WebSocket 调试、路由接口切换、未保存取消离开以及手机布局。

强调色验证覆盖红色到绿色的自动同步、深浅模式切换、保持 Web 阅读设置、无效颜色回退及亮色按钮文字对比度。

Web 类型检查、ESLint 和 Vite 生产构建已验证。当前环境的 pnpm 包装器尝试自动重装依赖并因无终端中止，因此使用已安装依赖的 Node 入口执行相同的类型检查、Vite 构建和同步脚本，未更改依赖。产物手动同步至 `app/src/main/assets/web/vue/`；此目录的旧构建 assets 被替换，避免累计旧哈希文件。
