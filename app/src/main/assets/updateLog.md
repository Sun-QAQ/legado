**2026/10/05**
* Web 新增 AI 对话页面，可使用 App 中配置的供应商、角色和会话，支持获取模型列表、切换模型，以及上传图片和文本附件。
* 修复 Web AI 回复中的 Markdown 图片无法显示、图片代理超时后动图变为静态图片的问题。
* 优化 Web 漫画阅读：支持点击图片左右区域翻页，翻页箭头随鼠标位置显示，专注模式铺满浏览器并支持按 Esc 退出。
* Web 阅读章节目录统一为单列；侧栏支持收起、展开并记住状态，进入页面时默认收起。
* 传书功能整合到 Web 工作区，优化上传界面和入口。
* AI 供应商支持按模型配置思考开关和强度，获取模型列表后显示成功或失败提示。
* 源变量弹窗支持编辑并保存说明，优化长内容滚动；加载失败详情支持长按选择和复制。
* 修复 AI 对话弹出键盘时消息未跟随上移、阅读记录排序选中项显示错误，以及旧版 Android 的取色与光标着色兼容问题。
* 完善多语言文案、脚本参数诊断和脚本字符串处理，优化菜单、弹窗等界面细节。
